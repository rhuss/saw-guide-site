Chart values

The tables below list every key in each chart’s values.yaml at the baseline, the default value, and a short description. The generator script scripts/gen-reference.sh produces them from the pinned sources.

Key Default Meaning

true

Toggle the interceptor Deployment.

ghcr.io/validatedpatterns-sandbox/governance-interceptor:v0.1.2

Container image for the governance interceptor Pod. A GitHub workflow builds the default and tags it with the OpenShell ref it is built from, which must match the gateways' OpenShell release.

keycloak.clients.cli.accessTokenLifespan sets the lifespan that the openshell-cli client requests, not the lifetime of the tokens it gets. Keycloak never issues an access token that outlives the user’s SSO session, and the realm keeps Keycloak’s default SSO Session Max of 10 hours. An access token is therefore valid for at most 10 hours, not 24 (see Token lifetime).
